# AI Skills

Free, open source Claude skills I build and use. Each folder is one skill with its own `SKILL.md`, a script you can also run on its own, and a README.

| Skill | What it does |
|---|---|
| [notebook-video-cleaner](notebook-video-cleaner) | Turns a NotebookLM explainer into branded videos for YouTube, Shorts, Reels and LinkedIn: trims the generic opening line, adds your logo, an AI disclosure label, intro and outro clips, levelled audio and a thumbnail, one file or a whole folder at a time |
